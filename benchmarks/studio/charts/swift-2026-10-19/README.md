# Swift performance on native TensorFold

October 19, 2026: TensorFold 1.1.1 on an M5 Max with 64 GiB. Upstream `d1018b3` is merged in [PR 3](https://github.com/araysuter/TensorFold/pull/3). Inference now uses native Zig and Metal rather than the historical Python/MLX engine. See `environment.json` for exact benchmark and deployed source revisions, binary hashes, pinned checkpoints and settings. The benchmark candidate and deployed main have identical native arithmetic; the main rebuild incorporates whitespace-only Metal cleanup.

The standard Swift benchmark completed **18 successful uncached requests in 12 batches**, exactly one attempt per context/concurrency setting. Each reply reached the 1,024-token limit. Context sizes are 20K, 40K, 60K, 80K, 100K and 128K, with one and two simultaneous submissions. Sampling is greedy, reasoning off and drafting on. Benchmark context is 131,072, parallel capacity 2, retained prompt budget 8 GiB, and prompt chunks 512 tokens. The deployed source build retains 5 GiB: its startup memory guard allowed about 5.3 GiB with two streams and rejected 8 GiB. No over-cap override is enabled; the cold benchmark had zero cache hits.

At 128K solo, generation is **55.2 tokens/s**, versus 50.5 in the original published run (+9.4%). Effective prompt throughput is **504.3 tokens/s**, versus 482.4 (+4.5%); first-token wait is **253.8 versus 265.4 seconds**. This is a small improvement against the original reference. Against the separately saved October 4 optimized run, cold 128K first-token wait increased from 198.5 to 253.8 seconds (+27.9%). The update does not establish a cold-prompt speed gain over that optimized build.

The blue/orange figure compares current one versus two users; the blue/pink figure compares current solo with the **original published Swift benchmark**, not October 4. The original reference retains three solo trials at 20K/40K/60K and one at 80K/100K/128K, with the higher-memory 128K rerun selected for the first published chart. Engines, historical configurations and public-versus-local HTTP differ; this is not a controlled A/B or a coding-quality measurement.

Prompt throughput is uncached tokens divided by **queue plus prefill**. Native API prefill duration excludes queue time, so `normalize_native.py` matched each response ID and token counts to its completion receipt, restored the logged queued duration and recomputed derived throughput. Queued durations have millisecond precision. Per-request rates use the median and observed range; combined output throughput uses total output divided by batch wall time. Whiskers are not confidence intervals. Large paired requests queue for native memory admission; their per-request generation rates must not be added.

The native host and Metal suite passed **4,769 tests with 15 skips, zero failures, and 372/372 build steps**. The final main rebuild passed 372/372 steps, executing 1,002 tests with 4 skips and reusing unchanged successful test targets. Desktop CI passed all **821 test files**, typecheck and whitespace; Linux native checks passed. Windows port repair is outside this Mac update. `tests.json` records the check receipts.

Swift checkpoint compatibility was verified across all 2,379 tensors: the separate prepared checkpoint applies the old loader's float32-add-one/BF16 conversion to exactly 161 RMSNorm vectors and preserves all other tensor bytes. Original downloads remain untouched. Six seeded 20K cold requests and short code/chat checks matched across draft/plain and concurrent/solo execution. Cached chat reused **20,056 prompt tokens**, reducing prompt processing from **22.29 to 0.044 seconds** with identical output. See `validation.json`.

A 2,048-token chunk trial saved only about 0.25% on the measured solo 20K prefill median while raising peak footprint about 4.7 GiB and reducing concurrent admission. The deployed default remains 512; see `chunk-trial.json`. This trial does not establish a globally optimal kernel configuration.

GPU device utilization sampled approximately once per second across the entire benchmark window had **99% median and 98.7% mean**. This includes preflight, gaps, prefill and decoding and does not measure tensor-core occupancy. Swap usage stayed at the pre-existing 981.81 MiB; 59 swap pages were read back and there were zero additional swap-outs. See `environment.json` for the counters. No thermal or performance warning was recorded.

`updated-results.json` contains normalized raw measurements with a portable output-directory label; `previous-results.json` preserves the original reference. `summary.csv` and `solo-comparison.csv` contain derived measurements. Both figures are available as PNG, SVG and PDF. `swift-performance.html` is the Page toggle source. Run `render_visualizations.py` in a Matplotlib environment and `build_page_visualization.py` to regenerate without running models. Raw server logs, keys and private filesystem paths are excluded.
